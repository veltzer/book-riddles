\section {Knight moves on a keypad (Algorithms)}

You are given a standard phone keypad:

\begin{verbatim}
1 2 3
4 5 6
7 8 9
  0
\end{verbatim}

A chess knight stands on one of the keys. Write a function

\begin{verbatim}
knight_combinations(from, n)
\end{verbatim}

that returns the number of different sequences of $n$ knight moves that start at the key \verb|from|.
For example, from the key $1$ there is $1$ sequence of $0$ moves, there are $2$ sequences of $1$ move: $(1,6)$ and $(1,8)$,
and there are $5$ sequences of $2$ moves: $(1,6,1)$, $(1,6,7)$, $(1,6,0)$, $(1,8,1)$ and $(1,8,3)$.

\subsection{Solution}

First write down where a knight can go from each key:

\begin{verbatim}
0 -> 4, 6        5 -> nowhere
1 -> 6, 8        6 -> 1, 7, 0
2 -> 7, 9        7 -> 2, 6
3 -> 4, 8        8 -> 1, 3
4 -> 3, 9, 0     9 -> 2, 4
\end{verbatim}

A sequence of $n$ moves from key $k$ is a first move to a neighbor $j$ followed by a sequence of $n-1$ moves from $j$, so
\begin{center}
$f(k, 0) = 1$, \quad $f(k, n) = \sum_{j \text{ a neighbor of } k} f(j, n-1)$
\end{center}
Computing this naively with recursion takes exponential time, but computing $f(\cdot, 1), f(\cdot, 2), \ldots, f(\cdot, n)$ one after the other,
each time for all 10 keys, takes $O(n)$ time and $O(1)$ memory.

We can do even better. Let $M$ be the $10 \times 10$ adjacency matrix of the keys: $M_{kj} = 1$ if a knight can move from $k$ to $j$ and $0$ otherwise.
The entry $(M^n)_{kj}$ is the number of sequences of $n$ moves from $k$ to $j$, so the answer is the sum of row $k$ of $M^n$.
Raising a matrix to the power $n$ by repeated squaring takes $O(\log n)$ matrix multiplications, so this solution takes $O(\log n)$ time.
For example, there are $3728$ sequences of $10$ moves starting from the key $1$.
